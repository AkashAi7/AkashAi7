## About

I build the tooling that makes AI-assisted engineering **measurable, affordable and safe to adopt at enterprise scale.**

Most of my work lives at the intersection of three things: **agentic developer tooling** (VS Code extensions and orchestration built on the GitHub Copilot SDK), **AI cost engineering** (token compression, AI-credit modelling, billing observability), and **cloud economics** (BOQ generation, multi-cloud TCO, competitive bid strategy for Azure vs. AWS/GCP).

```yaml
role:      Cloud & AI Solution Engineer @ Microsoft
based_in:  Bhopal, India
focus:     [ Agentic DevTools, AI Cost Engineering, Cloud FinOps, Azure + Kubernetes ]
building:  [ VS Code extensions, Copilot SDK agents, benchmark harnesses, enablement labs ]
ask_me_about:
  - Squeezing 40%+ out of your Copilot token bill without losing answer quality
  - Designing defensible Azure BOMs & BOQs for competitive RFPs
  - Shipping CI/CD to AKS with Azure Pipelines, ACR and agentic DevOps
open_to:   [ Developer tooling, applied GenAI, IoT & green tech collaborations ]
```
